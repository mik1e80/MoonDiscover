# MoonDiscover 维护路线

项目已通过报名初审。继续维护 IPv4 mDNS 查询端和 DNS-SD 浏览、解析基础库，范围、证据和发布状态分别记录。IPv6 组播、macOS 适配、自动接口迁移和服务发布属于后续里程碑。现行边界见 [SCOPE](SCOPE.md)。

| 工作 | 验收依据 |
| --- | --- |
| 查询端协议 | 按 RFC 1035、2782、6762、6763 与 4034 §4.1 映射代码和测试。维护 Additional、正负证据、TTL、Known-Answer 和恢复。RFC 6762 §7.3 当前实现受限单问题路径。同机双响应器、双查询器和 zeroconf 的无续包内部等待已取得证据，更多查询器、持续 TC、跨设备仍列入待验收 |
| 输入与稳定性 | Wire、Cache、Engine、Replay 变异按入口风险选择。保存已修复的失败回归，观测拒绝时的快照、容量、时间和资源释放 |
| 兼容性 | Windows/Linux 关键 Native 路径、JS 核心与回放。第二设备、Bonjour、真实换网和长时压力分别记录，平台声明以对应实测为准 |
| 说明和依赖 | 修改协议行为时同步 README、范围、RFC 表、模型、诊断和变更日志。依赖更新单独记录精确版本、许可证及来源 |
| 发布 | 确认 API 由独立工程消费，候选包许可齐全，构建来源与标签一致。正式发布后验证注册表独立安装，并记录包散列和发布证据 |

每次提交聚焦一个有实际结果的任务。代码变更记录触发条件、协议依据、定向测试和兼容性。文档修改检查一致性和链接。安全缺陷按仓库安全政策报告。当前验证和剩余发布条件见 [0.3.0 预发布验收](release-acceptance-0.3.0.md)。
